title: "Discuss issues and tweak results"
description: "Find issues with Corra, discuss an issue or a portal's insights with it, and ask it to change a prompt analysis or a job figure."
---

Corra has three kinds of conversation in the app. They share one pattern: Corra reads, answers, and changes something only when you approve it or when the page applies the result in an editor you control.

## Find issues

**Find issues with Corra** is on the **Issues** page of an annotation queue and of a Feedback Portal. Corra reads the records and groups recurring problems into issues. The steps, settings and the skill that guides Corra are in [Finding issues](/deploy-and-monitor/annotation-queue-issues/). Portal issues are described in [Feedback Portals](/evaluate-and-approve/feedback-portals/).

## Discuss with Corra

Open an issue and click **Discuss with Corra**. A panel opens next to the issue. Ask whether the issue is real, what else shows it, or what to do. Corra reads the records, ratings and comments, and counts and filters them before it answers.

- Whoever can read the issue can talk to Corra about it. Your discussion is private to you and is kept under your user.
- In a queue issue, Corra can propose to **add evidence** or **comment on the issue**. Each proposal appears as a card that shows exactly what will be done. Click **Approve** or **Reject**. Nothing changes until you approve, and you need write access.
- If the connection drops, click **Reconnect**. If the same issue is open with Corra in another window, close it there first.

On a Feedback Portal's **Insights** page, **Discuss with Corra** opens a chat about the insights as shown: the reviewed chats, thumbs, agent versions, reviewers and issues. That chat reads and answers; it changes nothing.

## Tweak a prompt analysis

On a prompt, **Analyze** scores the prompt and lists findings with fixes. Click **Tweak this analysis with Corra** to open **Talk to Corra**. Ask for a change, or ask why a finding is there. When Corra submits a new version, it replaces the analysis you see. **Check against a goal** has the same button, **Tweak this check with Corra**. Whoever can read the prompt can use it. See [Prompts](/register-and-refine/inventory-management/prompts/).

## Edit a job figure

On a job's report, describe a chart or table under **What do you want to see?** and click **Generate figure**. Corra writes the figure's code from the columns of the evaluation, including columns hidden from Job Results. To change the figure, click **Edit with Corra** and ask for a change. The new code replaces what the editor shows, but nothing is saved or run until you do it. You need edit access to the object the job ran on.

The **Talk to Corra** panel says "Ask Corra to change the result; the new version replaces the one you see." A message together with the result may not exceed 16,000 characters.
