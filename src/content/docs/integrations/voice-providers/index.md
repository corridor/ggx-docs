---
title: "Voice providers"
description: "Connect voice AI providers such as Deepgram to GGX with an API key."
---

Voice providers supply speech-to-text, text-to-speech, and voice agent capabilities. Connect one in **Org Settings → Integrations → Voice providers**.

| Integration | What it does |
| --- | --- |
| [Deepgram](deepgram/) | Speech-to-text, text-to-speech, and voice agents. |
