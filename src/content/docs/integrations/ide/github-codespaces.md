[GitHub Codespaces](https://github.com/features/codespaces) provides development environments hosted on GitHub. GGX lists it as an IDE provider.

## What it does in GGX

- Lists GitHub Codespaces under **IDE/Notebook Integrations** in **Org Settings → Integrations** with the description "Integrate with codespaces hosted on GitHub".
- When the GGX Team has configured it for your organization, adds GitHub Codespaces to the **IDEs** section of the profile menu. Selecting it opens the saved URL in a new browser tab.

## How to connect

You do not configure this integration yourself. In **Org Settings → Integrations → IDE/Notebook Integrations**, **Configure** on GitHub Codespaces shows "Not available - contact the GGX Team to configure this". Ask the GGX Team to set it up for your organization.

## Notes

- The setting is per organization. Every user of the organization sees the same menu entry.
- The URL opens in a separate tab. GGX does not embed the environment.
- For an IDE you configure yourself, see [JupyterHub](jupyterhub/).
