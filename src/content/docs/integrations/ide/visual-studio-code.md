[Visual Studio Code](https://code.visualstudio.com/) is a code editor. GGX lists it as an IDE provider for a browser-based VS Code environment.

## What it does in GGX

- Lists Visual Studio Code under **IDE/Notebook Integrations** in **Org Settings → Integrations** with the description "Browser-based VS Code development environment".
- When the GGX Team has configured it for your organization, adds Visual Studio Code to the **IDEs** section of the profile menu. Selecting it opens the saved URL in a new browser tab.

## How to connect

You do not configure this integration yourself. In **Org Settings → Integrations → IDE/Notebook Integrations**, **Configure** on Visual Studio Code shows "Not available - contact the GGX Team to configure this". Ask the GGX Team to set it up for your organization.

## Notes

- The setting is per organization. Every user of the organization sees the same menu entry.
- The URL opens in a separate tab. GGX does not embed the environment.
- For an IDE you configure yourself, see [JupyterHub](jupyterhub/).
