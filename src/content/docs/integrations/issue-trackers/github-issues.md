[GitHub Issues](https://docs.github.com/en/issues) is GitHub's issue tracker. GGX uses it to turn issues found in annotation queues and feedback portals into GitHub issues.

## What it does in GGX

- Create a GitHub issue from a GGX issue (Issues Found) in a repository you pick.
- Link an existing GitHub issue by number or URL.
- Show each linked issue's status in GGX and refresh it in the background and on demand.
- GitHub has two states, open and closed, so GGX shows the state GitHub reports and maps closed issues to a resolved outcome.

## How to connect

GitHub Issues needs no connection of its own. It uses the GitHub connection that each person already makes for Code Repos. See [GitHub](../../source-control/github/). The GenGuardX GitHub App must be allowed **Issues (read and write)** on the repositories you use; reconnect GitHub if GitHub asks for more access.

## Notes

- GitHub issue types belong to the organization and are not chosen in GGX.
