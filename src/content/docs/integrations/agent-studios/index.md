---
title: "Agent studios"
description: "Register agents built in Agentforce, Copilot Studio, Dialogflow CX, Amazon Lex, and other agent studios in GGX for testing and governance."
---

Agent studios are platforms where teams build and host conversational AI agents. Connect one in **Org Settings → Integrations → Agent studios** and GGX can register those agents, so they are tested, evaluated, and governed like any other agent.

| Integration | What it does |
| --- | --- |
| [Agentforce (Salesforce)](agentforce/) | Register autonomous Agentforce agents. |
| [Vertex AI Agent Playbooks](vertex-ai-agent-playbooks/) | Register Google Cloud playbook-based conversational agents. |
| [Microsoft Copilot Studio](microsoft-copilot-studio/) | Register low-code Copilot Studio agents. |
| [GitHub Copilot](github-copilot/) | Register GitHub Copilot chat as an agent. |
| [Vapi AI](vapi-ai/) | Register Vapi assistants as chat agents. |
| [Amazon Lex](amazon-lex/) | Register Amazon Lex V2 bots. |
| [CustomGPT](customgpt/) | Register CustomGPT agents. |
| [Dialogflow CX](dialogflow-cx/) | Register Google Cloud Dialogflow CX agents. |
