[Microsoft Copilot Studio](https://www.microsoft.com/microsoft-copilot/microsoft-copilot-studio) is a low-code platform for creating AI-powered agents. GGX uses it to register Copilot Studio agents for testing and governance.

## What it does in GGX

- Register an agent built on Microsoft Copilot Studio in GGX, so it can be tested, evaluated, and governed like any other agent.
- GGX provides starter run logic for Microsoft Copilot Studio that sends a user message to the agent and returns its reply, which you adapt to your agent.
- Once registered, the agent can be used in simulations, judges, and reviews alongside your other agents.

## How to connect

1. In GGX, open **Org Settings → Integrations → Agent studios** and select **Microsoft Copilot Studio**.
2. Provide the API key and endpoint of your Copilot Studio agent.
3. Save. Authorized users can then create an agent that uses Microsoft Copilot Studio.
