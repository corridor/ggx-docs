[GitHub Copilot](https://github.com/features/copilot) is GitHub's AI coding assistant. GGX uses its chat as an agent that can be registered for testing and governance.

## What it does in GGX

- Register an agent built on GitHub Copilot in GGX, so it can be tested, evaluated, and governed like any other agent.
- GGX provides starter run logic for GitHub Copilot that sends a user message to the agent and returns its reply, which you adapt to your agent.
- Once registered, the agent can be used in simulations, judges, and reviews alongside your other agents.

## How to connect

1. In GGX, open **Org Settings → Integrations → Agent studios** and select **GitHub Copilot**.
2. Provide a GitHub token that is allowed to use Copilot chat.
3. Save. Authorized users can then create an agent that uses GitHub Copilot.
