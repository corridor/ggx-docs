[Agentforce](https://www.salesforce.com/agentforce/) is Salesforce's platform for autonomous AI agents that work with Salesforce data and workflows. GGX uses it to register Agentforce agents for testing and governance.

## What it does in GGX

- Register an agent built on Agentforce (Salesforce) in GGX, so it can be tested, evaluated, and governed like any other agent.
- GGX provides starter run logic for Agentforce (Salesforce) that sends a user message to the agent and returns its reply, which you adapt to your agent.
- Once registered, the agent can be used in simulations, judges, and reviews alongside your other agents.

## How to connect

1. In GGX, open **Org Settings → Integrations → Agent studios** and select **Agentforce (Salesforce)**.
2. Provide the connected app's client ID, its client secret, and your Salesforce domain URL.
3. Save. Authorized users can then create an agent that uses Agentforce (Salesforce).
