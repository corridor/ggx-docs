---

[Perspective API](https://perspectiveapi.com/) provides reporting and evaluations. GGX can connect it as a judge.

## What it does in GGX

- Make Perspective API available to the organization so its evaluations can be used in GGX reports.

## How to connect

1. In GGX, open **Org Settings → Integrations → Judges** and select **Perspective API**.
2. Enter your API key. GGX makes it available to your code as `PERSPECTIVE_API_KEY`.
3. Save.

## Notes

- A project can use its own credentials instead of the organization's.
