---
title: "Evaluation providers"
description: "Connect external evaluation and guardrail providers such as Cleanlab, MedBAR, and Guardrails AI to GGX."
---

Evaluation providers add external trust, safety, and quality signals to GGX assessments and judges. Connect them in **Org Settings → Integrations → Judges**.

| Integration | What it does |
| --- | --- |
| [Cleanlab](cleanlab/) | Trustworthiness scores and data quality checks for agents, RAG, and datasets. |
| [MedBAR](medbar/) | Question plans and medical evaluations. |
| [Guardrails AI](guardrails-ai/) | Input and output guardrails for LLM applications. |
