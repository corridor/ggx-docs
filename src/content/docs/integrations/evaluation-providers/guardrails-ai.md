[Guardrails AI](https://www.guardrailsai.com/) provides input and output guardrails to harden LLM applications. GGX can connect it as a provider of guardrail checks.

## What it does in GGX

- Make Guardrails AI available to the organization so its input and output guardrails can be used with GGX workflows.

## How to connect

1. In GGX, open **Org Settings → Integrations → Judges** and select **Guardrails AI**.
2. Enter your API key and, if you host Guardrails yourself, its base URL. Save.

## Notes

- A project can use its own credentials instead of the organization's.
